# Source and artifact terms

The ACL template is copied from the official author-template repository at
the revision documented in `paper/template/SOURCE_AND_REQUIREMENTS.md`.
Its component notices are preserved. No blanket license is asserted over
third-party template files or the official website snapshots.

Model weights and datasets retain their upstream terms. See `docs/data.md`
and the pinned model card for access and license details. They are not
redistributed with this source tree.

Original project code and documentation are released under MIT. The manuscript
and third-party materials are excluded from that grant. Separately hosted model
adapters/heads and processor files use Apache-2.0; their model repository includes
the upstream license and a changes notice. Base-model weights are not bundled.
